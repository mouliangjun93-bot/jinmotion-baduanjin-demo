# JinMotion / 锦行 / 錦行

[English](README.md) | 简体中文

一个支持三语界面、通过手机摄像头辅助八段锦练习的研究原型，当前版本为 **0.2.4**。

**在线演示：** [打开 JinMotion](https://jinmotion-baduanjin.netlify.app/)

本项目用于展示早期软件开发的可行性。目前尚未经过临床评估或治疗效果验证，也不代表 Study 2 已完成，或已经取得相关研究结果。

## 目前支持的功能

- 简体中文、以繁体字呈现的港式粤语、英语界面；默认语言为粤语。
- 八段锦八式图示库、可编辑的示例练习计划、练习计时、手动次数记录、疼痛与主观用力程度记录、练习草稿恢复，以及 CSV/JSON 导出和导入。
- 全屏摄像头画面，支持前后摄像头选择；浏览器开放相应硬件能力时，可使用镜头缩放。
- 实验性的二维**髋—膝—踝三点夹角**测量，肢体伸直时约为 180°。该数值尚不能作为经过验证的解剖学膝关节屈曲角度。
- 在同一帧画面上叠加身体关键点和角度，并检查追踪置信度、身体是否进入画面，以及关键点是否出现不稳定。
- 根据界面语言，使用设备可用的普通话、粤语或英语语音提示用户调整位置和镜头；支持延迟提醒、提醒间隔控制、静音和语音试听。
- 模型资源在本地校验和缓存，支持保留已完成的下载分块，并在下载失败时重试。

## 局限与研究阶段

本项目使用 Google 预训练的 **MediaPipe Pose Landmarker Full** 提供通用人体关键点。目前没有训练专门识别八段锦动作的模型。衣物遮挡、身体遮挡、镜头方向、镜头畸变，以及模型在置信度较高时仍然给出错误关键点等情况，都可能影响测量。现有技术检查无法识别所有错误。

**目前尚未实现**八段锦动作分类、具有临床意义的动作质量评分、自动次数统计、个体化运动处方，以及经过验证的动作纠错反馈。现有语音主要提示镜头位置和追踪质量。动作图示与示例练习量仅用于演示，尚不能作为经过验证的教学或治疗建议。

本项目计划用于支持后续研究开发：由 **Study 1** 提供动作证据与专家规则，在 **Study 2** 完成系统开发、独立技术验证与反馈验证，再将版本固定的系统投入 **Study 3**。软件测试通过不等于测量准确性或临床获益已经得到证明。

## 本地运行

环境要求：**Node.js 22 或更新版本、Python 3.9 或更新版本**；首次准备上游模型与运行资源时需要联网。

```sh
npm ci --ignore-scripts
npm run prepare:assets
npm test
npm start
```

启动后打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。应用使用 ES modules，请通过上述本地服务运行，不要直接双击 `index.html`。

摄像头功能需要 localhost 或 HTTPS 等安全上下文，并需要用户授权。手机通过普通 HTTP 局域网地址访问电脑，并不等同于在手机上访问 localhost。

源码仓库不包含模型权重、生成的二进制分块、下载的第三方可执行资源、本地托管信息或测试照片。`prepare:assets` 会下载固定版本的 MediaPipe 1.2.2 / fflate 0.8.2 运行文件及官方 Full float16 v1 模型，校验文件大小与 SHA-256 哈希，并在本地生成压缩分块。上游下载地址无法访问时，资源准备可能失败；在线演示独立部署。第三方原始许可证保留在 `dist/vendor/` 中。

## 测试与可复现性

当前测试套件包含 **47 项软件测试**，覆盖角度几何计算、状态恢复、备份导入、同帧画面叠加、摄像头控制、资源完整性、下载重试与缓存，以及不同语言的语音行为。

桌面浏览器基础测试已运行模型推理，并检查语音所用语言是否匹配。这些测试尚不能证明真实使用环境下 iPhone / Android 的测量准确性、设备兼容性或性能。本仓库不包含参与者验证数据集或临床研究结果。

完成 `prepare:assets` 后，可生成用于 Netlify 静态部署的 ZIP：

```sh
python3 pack-netlify.py
```

输出文件为 `release/jinmotion-netlify.zip`。将源码上传 GitHub 与将可运行网页部署到 Netlify 是两个独立步骤。

## 隐私与数据

本原型无需账号，没有后端或云端同步。练习记录和数值样本保存在当前浏览器的 localStorage 中。摄像头画面在设备端处理，应用不会录制或上传画面。浏览器语音服务按各自实现方式接收固定提示文本；应用不使用麦克风。清除浏览器存储会删除本地记录，有需要时请先导出 JSON 备份。

请勿将真实参与者数据、个人健康记录、录音录像、账号令牌或部署凭据提交至仓库。导出的练习记录与原始研究计划书均不属于本仓库内容。
